Time Series Forecasting
for natural gas consumption

About the project

Summary:

This project focuses on forecasting natural gas demand in Greece for the 12-month period from August 2024 to July 2025. Using historical consumption and temperature data, multiple forecasting models are developed and compared to evaluate their ability to capture seasonal trends, weather-driven fluctuations, and long-term dependencies in energy usage.


Tools used:

The models were implemented in Python, using key libraries such as pandas, NumPy, and scikit-learn for data preprocessing and feature engineering. Time series models were developed using statsmodels, XGBoost and Tensorflow 2. Weather data was retrieved via the Meteostat API and aggregated into monthly averages for integration with consumption data.


Project details:

This project explores a range of forecasting approaches, spanning traditional statistical models, machine learning methods, and advanced deep learning architectures:
➤ SARIMA (Seasonal Autoregressive Integrated Moving Average): A statistical baseline capable of modeling autocorrelation, trend, and seasonality in natural gas demand.
➤ XGBoost: A powerful ensemble method applied to engineered features such as lagged consumption values and temperature data.
➤ MLP (Multi-Layer Perceptron): A feedforward neural network that captures nonlinear relationships between past consumption, temperature, and future demand.
➤ RNN (Recurrent Neural Network): Designed to model sequential data, capturing short-term dependencies in gas consumption trends.
➤ LSTM (Long Short-Term Memory): A more advanced recurrent model capable of learning long-term dependencies and avoiding vanishing gradient issues.
➤ GRU (Gated Recurrent Unit): A streamlined alternative to LSTM with fewer parameters, offering a balance between efficiency and performance.
➤ 1D-CNN (1D - Convolutional Neural Network): Applied along the time axis to extract local temporal features and short-term fluctuations in demand.

The dataset includes historical monthly natural gas consumption in Greece (2008–2025) and was obtained from https://ec.europa.eu/eurostat/. Monthly average air temperatures were derived from daily records using the Meteostat API. The combined dataset enables both seasonal and weather-related effects to be incorporated into the models.

The study concludes with the creation of an interactive plot that visualizes actual consumption values alongside the forecasts, after which the performance of each model is evaluated..

Tools / Python libraries

For this project the following libraries-frameworks were used:

  • Pandas - data preprocessing and manipulation.

  • NumPy - numerical computations and array operations.

  • scikit-learn - feature engineering and machine learning utilities, including the MLPRegressor from sklearn.neural_network for fully connected neural network forecasting.

  • statsmodels - implementation of SARIMA model ( traditional time series model)

  • XGBoost - implementation of gradient boosting decision trees for tabular forecasting with lagged features and temperature data.

  • TensorFlow - building and training deep learning models (RNN, LSTM, GRU, 1D-CNN)

  • Meteostat API - used for retrieving daily weather data, aggregated into monthly averages for integration with consumption data.

  • matplotlib - used for creating static visualizations of actual and predicted values.

  • plotly used for building an interactive plot to compare all forecasts with actual consumption values.

Model evaluation

Error Metrics: MAE vs. RMSE
  • MAE (Mean Absolute Error):
    • Treats all errors equally.
    • More robust to outliers.
    • Useful when we care about the average magnitude of the forecasting error.
  • RMSE (Root Mean Squared Error):
    • Penalizes larger errors more heavily because of squaring.
    • More sensitive to outliers.
    • Preferred when large deviations are especially costly (e.g., underestimating winter peak demand).

➡ In energy consumption forecasting, RMSE is often prioritized, as peak-period accuracy is critical. However, MAE remains valuable for interpreting the typical average error.

Model Performance
  • Best overall: The LSTM model produced the most consistent forecasts, effectively capturing temporal dependencies.
  • Next best: GRU followed closely, performing well with slightly faster training compared to LSTM, making it a good balance between accuracy and efficiency.
  • Traditional model (SARIMA): provided stable forecasts even without temperature as an input.
  • Tree-based model (XGBoost): performed the weakest. With only 211 rows of data, it struggled to generalize, as tree-based models typically need larger datasets.
  • CNN & RNN: achieved relatively good results. Both RNN and CNN captured sequential patterns but both were outperformed by LSTM/GRU. CNN in particular requires larger datasets to fully leverage its strengths.
Training Times
  • Fastest - SARIMA: The SARIMA model trained almost instantly since it relies on fitting relatively few parameters. Its simplicity makes it computationally lightweight, ideal for quick baseline forecasts.
  • Fast - XGBoost: XGBoost also trained efficiently, even with engineered lag and temperature features. Gradient boosting decision trees scale well on small to medium-sized tabular datasets, making it a strong option when fast experimentation is needed.
  • Most demanding – Neural Networks: Deep learning models (MLP, RNN, CNN, GRU, and LSTM) required significantly longer training times. Among them, LSTM was the most computationally expensive, as its gating mechanisms and ability to capture long-term dependencies come at the cost of higher complexity and slower convergence. Despite this, the extra training time was justified by its superior forecasting accuracy.
Limitations
  • None of the models successfully captured the extreme peak consumption in January and February 2025. Despite incorporating temperature (average 8.7 °C in January, 8.2 °C in February), demand was underestimated. This suggests that temperature and historical consumption alone may not be sufficient. Additional explanatory variables (e.g., socioeconomic factors, policy changes, or unexpected demand shocks) could possibly help to better capture such anomalies.
